# 커뮤니티 설정

기능: 공개 코디 피드, 추천받은 코디 게시, 댓글, 하트 토글, 링크 공유, 본인 글·댓글 삭제.

## Supabase 연결

Supabase 플러그인을 설치·연결하면 프로젝트 `rwfjbdhfabwgefkwnwgn`에 `supabase/community.sql`을 적용할 수 있습니다.
직접 설정하려면 해당 프로젝트의 SQL Editor에서 파일 전체를 한 번 실행합니다.
이 파일은 기존 계정 데이터를 수정하지 않고 커뮤니티 테이블·인덱스·RLS 정책을 추가합니다.
브라우저에는 기존 공개 키만 사용하며 서비스 역할 키를 넣지 않습니다.

## 공개 범위와 권한

- 비회원: 게시물·댓글·하트 수 조회 및 링크 공유.
- 로그인 회원: 게시·댓글 작성, 하트 추가·취소.
- 작성자: 본인 게시물과 본인 댓글 삭제.
- 한 회원이 한 글에 남길 수 있는 하트는 기본 키로 한 개로 제한합니다.
- 게시물 삭제 시 연결된 댓글과 하트도 삭제됩니다.
- 게시물에 공개 닉네임·설명·추천 옷·캐릭터 설정을 저장합니다. 이메일과 실제 사진은 저장하지 않습니다.
- AI 생성 이미지는 업로드하지 않으며 저장한 옷과 캐릭터로 즉시 그림을 표시합니다.

## 확인

추천 결과에서 '선택한 코디 커뮤니티에 올리기'를 누르거나 상단 커뮤니티 메뉴에서 작성합니다.
다른 브라우저에서 공유 링크로 같은 게시물이 보이는지 확인합니다.
다른 계정에서는 남의 글 삭제가 허용되지 않아야 합니다.
테이블이 아직 없으면 준비 중 안내가 표시됩니다.

브라우저 모의 검사: `tests/community_browser_test.html`을 HTTP 서버 또는 로컬 파일로 열면
게시·하트 토글·댓글·삭제·게스트 권한·입력 처리·화면 전환·연결 오류 처리를 검증하고 body의 data-test에 결과를 표시합니다.
실제 데이터베이스의 RLS 검증은 SQL 적용 후 별도로 수행해야 합니다.
