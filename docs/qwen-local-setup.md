# PC에서 Qwen-Image-Edit 실행

API 키와 API 결제 없이 이 PC의 GPU로 실행하는 구성입니다. 외부 사용자용 상시 서버는 아닙니다. Supabase의 Gemini 함수는 이 모드에서 사용하지 않습니다. 기존 로그인과 캘린더 저장은 Supabase를 계속 사용합니다.

## 설치

VS Code PowerShell 터미널에서 프로젝트 폴더를 기준으로 실행하세요.

```powershell
powershell -ExecutionPolicy Bypass -File tools/qwen-local/install.ps1
powershell -ExecutionPolicy Bypass -File tools/qwen-local/start.ps1
```

브라우저에서 http://127.0.0.1:8000 을 여세요. Live Server 주소 대신 이 주소로 접속해야 합니다. 실행 터미널을 켜 두세요. 코디를 추천받으면 첫 코디를 자동 생성하며, 다른 코디는 버튼을 누릅니다. 로컬 이미지는 비로그인 사용자도 생성할 수 있습니다.

최초 생성 시 공식 Qwen/Qwen-Image-Edit 모델을 .qwen-cache에 다운로드합니다. 다운로드와 설치에는 수십 GB 이상의 여유 공간과 시간이 필요합니다. 다운로드 후 생성 시 API 요금은 없고 PC 전력과 자원을 사용합니다. 모델은 4비트 양자화하고 CPU/GPU에 나누어 올리도록 구성했습니다. RTX 4070 12GB / RAM 32GB에서 실제 메모리 사용과 생성 속도는 실행 검증이 필요합니다. 메모리가 부족하면 실행 창의 오류를 확인하세요. 여러 이미지를 동시에 만들지 않습니다.

현재 이미지는 결과 화면에서만 유지되며 캘린더에는 기존 옷 미리보기를 저장합니다. PC 서버는 127.0.0.1에만 바인딩합니다. 공개 사이트의 모든 사용자가 이 PC를 사용할 수 있는 구성은 아닙니다.

공식 모델: https://huggingface.co/Qwen/Qwen-Image-Edit
양자화 문서: https://huggingface.co/docs/diffusers/main/quicktour

Windows에서는 truststore로 시스템 인증서 저장소를 사용합니다. HTTPS 검증을 끄지 않습니다. 인증서 오류가 보이면 설치 스크립트로 의존성을 갱신하고 서버를 다시 실행하세요.

다운로드는 한 번에 파일 하나씩 받고 연결 오류 시 최대 30회 자동 재시도합니다. 기존 .incomplete 캐시를 유지해 이어받습니다. 별도로 다운로드만 진행하려면 `.qwen-venv/Scripts/python.exe tools/qwen-local/download_model.py`를 실행하세요. 상태는 .qwen-cache/download-status.json에 기록됩니다.
