# 자동 날씨

Open-Meteo의 현재 날씨 API를 사용하며 별도 인증키나 서버 설정이 필요하지 않습니다.
위치 허용 시 실제 위도·경도로 조회합니다. 화면에는 세부 주소 대신 ‘현재 위치’로 표시합니다.
정확한 위치는 계정 데이터에 저장하지 않습니다.

위치를 거부하거나 확인할 수 없으면 선택한 도시(처음에는 서울)의 날씨를 표시하고
위치 확인이 안 됐다는 안내를 함께 보여줍니다. ‘지역 바꾸기’에서 시/도와 시/군/구를 선택한 뒤 ‘이 지역으로 설정’을 누르거나
‘내 위치로 찾기’로 다시 요청할 수 있습니다. 선택한 도시는 다음 방문에도 유지됩니다.

기온, 체감온도, 습도, 바람, 날씨 상태와 데이터 기준 시각을 표시합니다.
현재 기온은 기존 추천 로직에 반영하고, 체감온도 선택 슬라이더는 사용자의 선택을 유지합니다.
조회에 실패하면 이전 도시의 온도를 추천에 사용하지 않습니다.
날씨는 현재 시점 기준이며, 미래 날짜의 약속 예보를 조회하는 기능은 아닙니다.

공개 HTTPS 사이트에서 위치 권한을 허용해 확인하세요.
페이지가 보일 때 15분 간격으로 갱신하며 수동 새로고침도 지원합니다.

무료 API는 비상업적 용도에 제공됩니다. 광고나 유료 서비스를 도입하면
Open-Meteo의 상업용 요금제 조건을 확인해야 합니다.
화면에 데이터 출처 링크를 표시합니다.
